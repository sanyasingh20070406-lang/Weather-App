# 🌦️ Weather App

A responsive weather application built using **HTML, CSS, JavaScript, and the Open-Meteo API**. Search for any city and view its current weather information through a clean and user-friendly dashboard.

## 🚀 Features

- 🔍 Search weather by city name.
- 🌡️ Display current temperature.
- 💧 Show humidity levels.
- 💨 Display wind speed.
- 🌧️ Show rainfall and precipitation.
- 🌤️ Weather descriptions and dynamic icons.
- ⏳ Loading indicator while fetching data.
- ⚠️ Error handling for invalid cities and network issues.
- 📱 Responsive design for desktop, tablet, and mobile.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- Open-Meteo Geocoding API
- Open-Meteo Weather Forecast API

## 🌐 API Used

This project uses the free [Open-Meteo API](https://open-meteo.com/) to retrieve geographical coordinates and weather information. No API key is required.
